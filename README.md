# Smartfaso

Application mobile multilingue (langues du Burkina Faso) pour accompagner les utilisateurs dans leur métier.

## Format
Application mobile (pas un site web).

## Page 1 : Inscription
- Nom, prénom et numéro de téléphone obligatoires.
- Refuser les lettres illisibles, les noms d'engins ou de villes et les numéros invalides.
- Impossible de passer à la page suivante tant que les informations ne sont pas correctes.

## Page 2 : Langue et métier
- Choix de la langue (français et langues du Burkina), texte lisible dans toutes les langues.
- Option « Lire » : lecture vocale naturelle dans la langue choisie, présente sur chaque page sauf la page des vidéos.
- Métiers disponibles, dont Comptable, Agriculture et Informatique.

## Page 3 : Questions
- Questions essentielles pour comprendre les difficultés de l'utilisateur.
- Impossible de continuer tant que toutes les questions n'ont pas de réponse.

## Page 4 : Conseils
- Conseils fixes selon les réponses.
- Si l'utilisateur change une réponse, les conseils changent aussi.

## Fonctions générales
- Calculs précis et sans erreur.
- Calculs, IA et vidéos dans la langue choisie.
- Vidéos : uniquement des formations du métier, dans la langue choisie (ex. dioula).
- Un calendrier dans chaque métier.
- Pour chaque métier : tout ce qui est utile aux utilisateurs.

## Agriculture
- Option Météo.
- L'appli indique quel métier convient le mieux à chaque zone.

## Informatique
- Coin d'apprentissage : exercices avec corrections et leçons.
- Langages : HTML, CSS, JavaScript, Python.
- Minimum 20 exercices et 15 leçons.
